# Antena 3 Noticias (1992) en 4K con IA

Código del remaster del informativo de Antena 3 del 28-09-1992, con Real-ESRGAN, CodeFormer y RIFE, ejecutado en local sobre Apple Silicon, y scripts y datos de la evaluación del artículo.

El archivo `remaster_antena3_1992.zip` está protegido con contraseña. Para obtenerla, escribe al autor: **javier.ortiz@ua.es**.

## Contenido
- `remaster4k.py`: proceso principal (modos lanczos, general, x4plus y caras).
- `rife/`: interpolación 25 → 50 fps, acabado de color y audio.
- `filtro_original.py`: mismo recorte y aspecto sobre el original para la comparativa.
- `experimento_articulo.command` y `evaluacion/`: variantes evaluadas, scripts y medidas.
- `registro_tiempos.csv`: tiempos medidos de cada ejecución.

No se incluye material audiovisual: los derechos pertenecen a Atresmedia Corporación de Medios de Comunicación, S.A. Uso exclusivamente docente y de investigación, sin ánimo de lucro.

Para abrir el archivo en macOS puede usarse la Utilidad de Archivo (doble clic) o The Unarchiver; en Windows, el Explorador o 7-Zip.
