# Cabeceras de informativos en 4K con IA

Código y datos del informe técnico *Remasterización 4K con IA de cabeceras de informativos: Antena 3, TVE y Telecinco* (Javier Ortiz Zamora, Universidad de Alicante).

El archivo `cabeceras_informativos.zip` está protegido con contraseña. Para obtenerla, escribe al autor: **javier.ortiz@ua.es**.

## Contenido
- Banco de pruebas con siete métodos de superresolución (Lanczos, Real-ESRGAN general a dos escalas y con limpieza fuerte, AnimeVideo v3 y RealESRGAN_x4plus).
- Estimación del detalle real de cada copia.
- Preparación (25 fps, recorte, antibloques y limpieza), superresolución a 4K y paso a 50 fps con RIFE 4.9.
- Generación del vídeo antes/después con detalle ampliado.
- Medidas de nitidez y tablas de resultados.

No se incluye material audiovisual: los derechos pertenecen a Atresmedia, RTVE y Mediaset España.

Para abrir el archivo en macOS puede usarse la Utilidad de Archivo (doble clic) o The Unarchiver; en Windows, el Explorador o 7-Zip.
